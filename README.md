# # 💅 Amore Belleza

Sitio web elegante y moderno para catálogo de productos de belleza y cosméticos.

## ✨ Características

- 🎨 Diseño con paleta de colores pastel
- 📱 Totalmente responsive
- 🖱️ Menú de navegación interactivo con arrastre
- 🛍️ Catálogo de productos con badges de estado
- 💎 Tipografías elegantes y femeninas
- ⚡ Interfaz fluida y moderna

## 🚀 Tecnologías Utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)
- Bootstrap 5
- Font Awesome 6
- Google Fonts (Cormorant Garamond, Poppins)

## 🎯 Funcionalidades Principales

### Menú de Navegación Deslizante

- Navegación con flechas
- Arrastre con mouse o touch
- Transiciones suaves
- Indicador de sección activa

### Tarjetas de Productos

- Imágenes optimizadas
- Badges de estado (Disponible, Sin Stock, Promo, Nuevo)
- Precios destacados
- Botones de acción
- Hover effects elegantes

## 🛠️ Instalación

1. Clona el repositorio:

```bash
git clone https://github.com/tu-usuario/amore-belleza.git
```

2. Abre `index.html` en tu navegador

¡No requiere instalación de dependencias! Todo funciona directamente en el navegador.

## 🎨 Personalización

### Cambiar Colores

Modifica las variables en `style.css`:

```css
:root {
	--primary-color: #ffe5ec;
	--text-color: #333;
	--accent-color: #a8d5ba;
}
```

### Agregar Productos

Duplica el bloque de producto en `index.html` y actualiza:

- Imagen (`src`)
- Título
- Descripción
- Precio
- Badge de estado
